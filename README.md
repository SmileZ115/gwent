# Gwent Clone

A card game inspired by Gwent from The Witcher 3, built with Godot 4 and GDScript.

## About

This is a learning project — a functional clone of the Gwent card game featuring player vs AI gameplay, turn-based logic, and score tracking.

## Features

- Player vs AI with randomized decks
- Turn-based system with automatic AI moves
- Score tracking for both sides
- Pass turn option
- Cards from The Witcher universe (Geralt, Yennefer, Ciri, and more)

## Built With

- [Godot Engine 4](https://godotengine.org/)
- GDScript

## How to Run

1. Download and install [Godot 4](https://godotengine.org/download)
2. Clone this repository
3. Open Godot, click **Import** and select the project folder
4. Press **F5** to run
